### 📝 Что сохраняется

При добавлении поста в JSON:
- ✅ **messageId** - номер сообщения в канале (число)
- ✅ **text** - полный текст сообщения (строка)
- ✅ **media** - объект с type и count (для фото, видео и т.д.)
- ✅ **replyTo** - ID сообщения, на которое это ответ (или null)
- ✅ **addedAt** - дата и время добавления

## 🎯 Как использовать

### Способ 1️⃣: Автоматическое добавление (РЕКОМЕНДУЕТСЯ)

Это самый надёжный способ. Бот автоматически ловит все новые посты:

```bash
# Запустите бота
npm start

# Отправьте посты в канал
# Бот их автоматически добавит в existing_posts.json
```

**Как это работает:**
- Бот слушает событие `channel_post` в Telegram
- Когда пост появляется в канале - бот его захватывает
- Определяет тип медиа, текст и ответы
- Добавляет в JSON файл

**Что видите в консоли:**
```
✅ #1: фото(x2) | "Привет! Смотрите фото..."
✅ #2: видео(x1) | "Смотрите видео..."
✅ #3: текст | "Классный пост!"
```

### Способ 2️⃣: Синхронизация существующих постов

Если в канале уже есть посты:

```bash
node sync-existing-posts.js
```

⚠️ **Ограничение:** Telegram API не разрешает копировать все сообщения. Скрипт получит только те, которые можно скопировать.

### Способ 3️⃣: Вручную добавить из JS

```javascript
const ExistingPosts = require('./services/ExistingPosts');

// Добавляем пост
await ExistingPosts.addPost(
    1,                              // messageId
    'Привет!',                      // text
    { type: 'фото', count: 2 },    // media
    null                            // replyTo
);

// Проверяем что добавилось
const allPosts = await ExistingPosts.getAll();
console.log(`Всего постов: ${allPosts.length}`);
```

## ❓ Часто задаваемые вопросы

**Q: Текст не добавляется?**  
A: Убедитесь что пост содержит текст или caption (описание медиа).

**Q: Медиа не распознаются?**  
A: Проверьте что медиа находятся в списке поддерживаемых типов выше.

**Q: Почему sync-existing-posts.js выдаёт ошибку?**  
A: Это нормально - не все сообщения можно скопировать через API. Используйте Способ 1.

**Q: Как удалить пост из JSON?**  
A: 
```javascript
const ExistingPosts = require('./services/ExistingPosts');
await ExistingPosts.removePost(1); // Удалить пост #1
```

**Q: Можно ли редактировать пост в JSON?**  
A: Напрямую нет, но можно удалить и добавить новый.

## 📝 Итоговый алгоритм

1. **Бот запущен** (`npm start`)
2. **Пост отправлен в канал**
3. **Telegram отправляет событие `channel_post`**
4. **BotService.handleChannelPost() перехватывает**
5. **Определяется тип медиа и текст**
6. **ExistingPosts.addPost() сохраняет в JSON**
7. **В консоли видите:** `✅ #X: ... | "..."`
