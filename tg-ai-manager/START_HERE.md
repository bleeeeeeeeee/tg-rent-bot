# ⚡ БЫСТРЫЙ СТАРТ - Заполнение ExistingPosts

## 🎯 В 3 шага

### Шаг 1: Запустите бота
```bash
npm start
```

Должны увидеть в консоли:
```
🤖 Бот готов к работе!
💬 Слушаю сообщения...
```

### Шаг 2: Отправьте пост в Telegram канал

Отправьте собщение в ваш канал:
- **Текст** - просто текс
- **Фото** - одно или несколько (альбом)
- **Видео** - видеозапись
- **Документ** - файл
- **И т.д.**

### Шаг 3: Проверьте консоль

Должны увидеть:
```
✅ #1: фото(x2) | "Ваш текст..."
```

## 📂 Проверьте JSON

```bash
cat storage/existing_posts.json
```

Должно быть:
```json
{
  "posts": [
    {
      "messageId": 1,
      "text": "Ваш текст",
      "media": {"type": "фото", "count": 2},
      "replyTo": null,
      "addedAt": "2026-02-28T..."
    }
  ]
}
```

## ❓ Если не работает

**Проблема:** Ничего не добавляется  
**Решение:** 
1. Убедитесь что бот может читать канал (добавьте его админом)
2. Отправьте пост в канал (не используйте старые)
3. Посмотрите консоль

**Проблема:** sync-existing-posts.js выдаёт ошибку  
**Решение:** Это нормально - используйте Способ 1 (npm start)
