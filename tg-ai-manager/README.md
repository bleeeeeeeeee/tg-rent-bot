# tg-ai-manager

Небольшой менеджер для публикации объявлений в телеграм-канал с поддержкой черновиков, календаря, истории и ИИ-суммаризации.

## Возможности

- **Публикация** из любого чата (текст, фото, видео).
- **Черновики**: сохранить, изменить, опубликовать сразу или по расписанию.
- **Планирование**: выбрать дату/время через календарь.
- История: ведётся файл `storage/history.json` с публикациями. Каждая запись содержит заголовок, основную мысль, описание и дату (генерируется OpenAI). Если пост содержит несколько медиа (альбом), они считаются **одним постом**; если сообщение является ответом на предыдущий, запись помечается `replyTo` и при показе выводится указание, на какой пост отвечено.
- Автоматическая **синхронизация** всех сообщений из канала при запуске (и при ручном `/sync`). История стремится покрыть **точно столько записей, сколько есть в канале**; дубликаты и связанные медиа сохраняются как единый элемент, ответы помечаются, удалённые сообщения автоматически вырезаются при следующей синхронизации, а при редактировании текст заново обрабатывается через OpenAI.
- История обновляется при редактировании постов в канале и при добавлении новых публикаций ботом.
- Основное меню всегда доступно кнопкой «Главное меню» в нижней клавиатуре или командой `/start`.  

## Требования

- Node.js 18+.
- Токен бота Telegram.
- ID администратора (ваш) и ID канала или `@username`.
- Ключ OpenAI (переменная `OPENAI_API_KEY`).

## Установка

```bash
cd tg-ai-manager
npm install
```

Создайте файл `.env` с содержимым:

```
BOT_TOKEN=123:ABC...
ADMIN_ID=123456789
CHANNEL_ID=-1001234567890
OPENAI_API_KEY=sk-...
```

## Запуск

```bash
npm start
```

Бот начнёт опрашивать сеть и при старте синхронизирует историю в фоновом режиме (без уведомлений).
После этого можно писать ему и использовать меню; если клавиатура остаётся на экране, она автоматически скрывается при выводе интерфейса с кнопками внутри сообщения.

## Развертывание

Можно запускать на любом сервере Node.js. Убедитесь, что запускается только один экземпляр бота (иначе Telegram вернёт 409).

Историю можно экспортировать через команду `/history` или меню. Вывод содержит **все** сообщения канала — если в посте нет текста, появляется пометка по типу `<фото>`, `<видео>`, `<аудио>` и т.п. Записи сортируются по дате **от старых к новым**: в начале сообщения (и в файле) идут первые публикации, в конце — самые свежие.

- **Показ истории в чате**: формируется единое сообщение (до 50 записей за раз) с датой в Минске (UTC+3), заголовком, основной мыслью, описанием, информацией о том, если это ответ, и ссылками на посты.
- **Файл с историей**: CSV с колонками `publishedAt,userId,chatId,messageId,replyTo,link,title,main,description,keywords`. Ссылка в файле полноценная (`https://t.me/...`) подходит для открытия на телефоне и ноутбуке. Поле `replyTo` содержит номер родительского поста, если таковой имеется.

> Бот **не удаляет** никаких сообщений: ни превью, ни копии во время синхронизации, ни свои собственные сообщения. Администратор может самостоятельно очищать чат, если нужно.
