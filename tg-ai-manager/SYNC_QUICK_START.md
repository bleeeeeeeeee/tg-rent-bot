# 🚀 Заполнение ExistingPosts - Быстрая инструкция

## Проблема

Скрипт `sync-existing-posts.js` не может скопировать старые посты из канала потому что Telegram API имеет ограничения.

## Решение: Используйте встроенный обработчик бота

### Шаг 1️⃣: Запустите бота

```bash
npm start
```

В консоли должны увидеть что-то вроде:
```
✅ запущен на PORT 3000
🤖 Бот готов к работе!
💬 Слушаю сообщения...
```

### Шаг 2️⃣: Отправьте пост в канал

Отправьте в ваш Telegram канал:
- 📝 Текстовое сообщение
- 🖼️ Фото (одно или альбом из нескольких)
- 🎬 Видео
- 📁 Документ
- И т.д.

### Шаг 3️⃣: Проверьте логи

В консоли должны увидеть:
```
✅ #1: фото(x2) | "Привет! Это пост..."
```

### Шаг 4️⃣: Проверьте JSON

```bash
cat storage/existing_posts.json
```

Должно быть:
```json
{
  "posts": [
    {
      "messageId": 1,
      "text": "Привет! Это пост...",
      "media": {"type": "фото", "count": 2},
      "replyTo": null,
      "addedAt": "2026-02-28T..."
    }
  ]
}
```

---

## ✅ Что будет автоматически собираться

Когда бот работает, он автоматически перехватывает все посты в канале:

- ✅ **Текст** - полностью сохраняется
- ✅ **Медиа** - распознаёт тип (фото, видео, аудио, документ и т.д.)
- ✅ **Количество** - считает сколько фото в альбоме
- ✅ **Ответы** - отмечает на какой пост это ответ (replyTo)
- ✅ **Дата** - сохраняет когда добавлен пост

## 🤔 Часто задаваемые вопросы

**Q: Почему sync-existing-posts.js не работает?**  
A: Telegram не разрешает копировать все сообщения. Лучше использовать обработчик бота который ловит события.

**Q: Как добавить уже существующие старые посты?**  
A: К сожалению, через API это сложно. Но вы можете:
   - Export из другого системы и импортировать вручную
   - Разместить ссылки в канале и бот их подберёт
   - Использовать отправку в админ-бот и пересилать в канал

**Q: Нужно ли останавливать бота после синхронизации?**  
A: Нет! Пусть работает постоянно. Он будет добавлять новые посты автоматически.

**Q: Можно ли запустить несколько ботов одновременно?**  
A: Нет! Telegram вернёт ошибку 409. Только один экземпляр.

**Q: Как проверить что бот поймал медиа?**  
A: В JSON файле должно быть поле `media` с `type` и `count`.

## 🎯 Итоговая инструкция

```bash
# 1. Запустите бота
npm start

# 2. В другом окне отправьте тестовый пост
# (просто отправьте сообщение в канал через Telegram)

# 3. Проверьте что добавилось
cat storage/existing_posts.json

# Готово! ✅
```

Каждый новый пост в канале будет автоматически добавляться в `existing_posts.json`!
